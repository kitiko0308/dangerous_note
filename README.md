# DANGEROUS NOTE

デスノートをモチーフにしたオンライン人狼ゲーム。

## 概要

プレイヤーは本名を隠しながらゲームを進行する。

キラ陣営は相手の名前を特定し、
デスノートに書くことで殺害できる。

市民陣営はキラを見つけ出し、
追放することで勝利する。

## ルール

- プレイヤーは本名とニックネームを持つ
- 本名は他プレイヤーには公開されない
- ミニゲームで負けると名前が1文字公開される
- キラは名前を完全一致で知ることで殺害可能
- Lは他プレイヤーの順位を調査できる

## 使用技術

- React
- TypeScript
- Vite
- Firebase（予定）
