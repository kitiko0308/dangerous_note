# DANGEROUS NOTE (デンジャラスノート)

Death Note をテーマにした Web 版人狼系ソーシャルディダクションゲーム。
React 19 + TypeScript + Vite で構築されています。

## ルール

### 勝利条件

| 役職 | 勝利条件 |
|------|---------|
| **キラ** | 5日目までに追放されない |
| **L / 市民** | キラを追放する |

- キラが5日目までに誰も殺せなかった場合はキラの敗北（L・市民の勝利）

### 役職

**キラ** — 「名前を書かれた人間は死ぬ。」
- 毎晩、ランダムで一人の本名の一文字を知ることができる
- ミニゲーム1位で【死神の目】を入手できる
- 5日目までに追放されなければ勝利
- 5日までに誰も殺せなかった場合は敗北

**L** — 「真実は、調査すればするほど浮かび上がる。」
- 毎晩、プレイヤー1人の順位を確認できる
- ミニゲーム1位で【ショートケーキ】を入手できる
- キラを追放できれば勝利
- キラが5日までに誰も殺せなかった場合も勝利

**市民** — 「君の力が未来を変える鍵になる。」
- 特殊能力は持たない
- 夜は「休む」を選ぶ
- 投票でキラを追放へ導く

### アイテム（ミニゲーム1位の報酬）

- **死神の目**: その夜、ランダムで誰か1人の本名を知る
- **ショートケーキ**: 1人を指定し、その人がキラかどうかを知る

### ゲームの流れ（1ターン）

| # | フェーズ | 説明 |
|---|---------|------|
| 1 | **朝** | 昨夜の結果を確認して話し合う |
| 2 | **ミニゲーム** | 最下位は本名の一部が全体に公表され、1位はアイテムを得る |
| 3 | **追放（投票）** | 投票で追放するプレイヤーを選ぶ |
| 4 | **夜** | 自陣営の勝利のために行動する |

最大5ターンでゲームが進行します。

## ミニゲーム

スマートフォン向けのミニゲームで、ターンごとの順位を決定します。


- **連打ゲーム**: 制限時間内に画面をタップした回数を競う
- **振るゲーム**（シェイク）: デバイスを振った回数を競う（iOS DeviceMotion 対応）
- **早押しゲーム**: 制限時間内にボタンを押す早さを競う

## 開発

```bash
cd client
npm install
npm run dev      # 開発サーバー起動
npm run build    # プロダクションビルド
```
